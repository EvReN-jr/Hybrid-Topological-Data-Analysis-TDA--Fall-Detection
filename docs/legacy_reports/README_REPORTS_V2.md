## Technical Implementation

| Component | Details |
|-----------|---------|
| **Optimization Method** | Optuna-based Bayesian hyperparameter search |
| **Feature Extraction** | Topological Data Analysis (TDA) with persistent homology |
| **Cross-Validation** | Subject-based leave-one-out (LOGO) |
| **Priority Metric** | F2 Score (β=2, emphasizes recall over precision) |
| **Parallel Processing** | 15 model jobs per optimization trial |
| **Feature Dimensions** | 24-dimensional topological feature vectors |
| **Repetitions** | n=10 (Naive), n=15/subject (General & Personal) |
| **Server Mode** | Tam (Full) server-side execution |
